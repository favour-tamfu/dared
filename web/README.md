# idared.org — application source

The Next.js application behind **[idared.org](https://idared.org)**, the website of DARED
(*Direct Action for Rights Equity and Development*), a Cameroonian non-profit.

This is the developer-facing README. For **adding events, adding documents, and getting
changes live**, read [`../MAINTENANCE.md`](../MAINTENANCE.md) instead — it assumes no
prior context. For the site itself, see [`../README.md`](../README.md).

## Stack

Next.js 16 (App Router) · React 19 · TypeScript 5 · Tailwind CSS v4 · static export.

The app compiles to plain HTML, CSS, and JS in `out/`. There is no server process, no
database, and no CMS: content is typed TypeScript, forms go to Formspree, and the built
files are uploaded to Namecheap shared hosting over FTPS.

## Commands

```bash
npm install
npm run dev            # dev server at http://localhost:3000
npm run build          # static export into out/
npm run lint           # ESLint
npm run deploy         # upload out/ to the live server over FTPS
npm run deploy:dry     # list what would upload, connect to nothing
npm run deploy -- --force   # re-upload everything, ignore size matches
```

`npm start` is not useful here — `next start` runs a Node server, and this project is a
static export. To check a production build, serve the folder: `npx serve out`.


## Conventions

**Content lives in `src/data/`.** `events.ts` drives the home page, the Events page, the
Gallery, the per-event routes generated by `generateStaticParams`, and `sitemap.xml`.
`documents.ts` drives the Resource Centre. Adding an entry is the whole job — nothing else
needs wiring.

**Use the design tokens.** The Toghu palette (`velvet-800`, `crimson-500`, `gold-300`,
`leaf-600`, `sand-100`) and the Fraunces/Inter font variables are declared in
`src/app/globals.css` under `@theme`. Reach for those and for the existing primitives
(`Container`, `PageHeader`, `Button`, `ToghuField`) rather than raw hex or one-off layout.

**No em-dashes in site copy.** Commas or "and" instead. `node scripts/dedash.mjs` sweeps
`.ts`, `.tsx`, and `.css` under `src/` if any slip in. Markdown files are exempt.

**Keep images under ~400 KB.** `node scripts/optimize-files.mjs public/images/foo.jpg`
resizes anything wider than 1920px at JPEG quality 82. Originals from the old site are
preserved on the `legacy` branch, so this is never destructive.

**Never edit `out/`.** It is regenerated by every build. Edit `src/`.

**Never commit secrets.** FTP credentials live in `.env.local`, which is gitignored.

## Static export gotchas

`next.config.ts` sets `output: 'export'`, `trailingSlash: true`, and
`images.unoptimized`. Consequences worth knowing:

- No route handlers, middleware, ISR, or server actions. Everything is resolved at build
  time.
- `next/image` runs unoptimized, so image weight is managed by the scripts above.
- Routes emit as `about/index.html`, which is what lets Apache serve clean URLs with no
  rewrite rules.
- `sitemap.ts` and `robots.ts` are forced static so they render into the export.

Tabbed and interactive UI is rendered fully into the static HTML rather than mounted on
demand — the Resource Centre renders all three tab panels with `hidden` on the inactive
ones, so crawlers and no-JS visitors see every document.

## Deploying

```bash
npm run build
npm run deploy
```

Then count `<loc>` entries at https://idared.org/sitemap.xml to confirm it landed. The
uploader is resumable, retries dropped connections, and never deletes — if it fails, just
run it again.

**Do not use cPanel's zip + Extract on this host.** It reports success and writes nothing.
The full story, plus credentials and troubleshooting, is in
[`../MAINTENANCE.md`](../MAINTENANCE.md).
